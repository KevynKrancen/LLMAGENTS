Video Generation Agentic Architecture

This diagram illustrates the multi-agent architecture for the video generation pipeline:

Key Components:

  • ToolCallingAgent: The central orchestrator that processes user requests and coordinates the video generation workflow
  • ToolCollection: Manages the available tools and capabilities that the agent can use
  • video_server.py: Provides an MCP-compatible interface for video operations
  • video_gen.py: Core implementation that orchestrates the video creation pipeline

External Services:

  • OpenAI API: Generates creative prompts and text for video content
  • Replicate API: Creates images based on prompts
  • SonAuto API: Produces music and audio for videos

Storage: Generated assets are stored in dedicated directories (image/, audio/, music/, video/)

Architecture Patterns Used:

  • Sequential: Processing flows from one step to the next (e.g., prompt → image → audio → video)
  • Parallel: Simultaneous processing of different assets (images, audio)
  • Loop: Iterative refinement of content until quality is achieved
  • Aggregator: Combining outputs from multiple sources into final video
