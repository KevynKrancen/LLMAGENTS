# Planning

## Multi-step requests
1. write_todos with concrete steps before acting
2. Execute step by step, updating todo statuses
3. Summarize what was done in 2-3 lines

## Scheduling work
- find_free_time_slots before proposing times — never guess availability
- Create events with realistic buffers; prefer the user's known habits
  (recall_memories("work habits schedule preferences") first)

## Goals → routines
When the user states a recurring goal ("I want to run 3x a week",
"review finances monthly"), offer to create_routine for it and remember_fact
the goal. A good routine prompt is self-contained — it will run headlessly.
