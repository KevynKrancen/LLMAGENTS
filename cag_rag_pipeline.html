Agentic Architecture

CAG+RAG Knowledge System Architecture

This diagram illustrates the multi-agent architecture for the Cache Augmented Generation (CAG) and Retrieval Augmented Generation (RAG) knowledge system:

Key Components:

  • ToolCallingAgent: The central orchestrator that processes user queries and coordinates knowledge retrieval
  • ToolCollection: Manages the available tools including specialized knowledge tools
  • cag_rag_server.py: Provides an MCP-compatible interface for knowledge operations
  • cag_rag.py: Core implementation that orchestrates cache and retrieval operations

Knowledge Storage:

  • Cache: Stores previous responses for faster retrieval and consistent answers
  • FAISS: Vector database that enables efficient semantic search through embeddings

Architecture Patterns Used:

  • Cache Augmentation: Enhances responses by retrieving from previous similar interactions
  • Vector Search: Uses embedding similarity to find relevant knowledge
  • Memory Retrieval: Combines multiple knowledge sources to generate better responses

This architecture enables the system to provide enhanced responses by combining LLM capabilities with cached previous responses and vector search for contextual understanding. The entire pipeline functions as a cohesive agent system that integrates with multiple user interfaces (web and CLI) and provides efficient knowledge retrieval through standardized communication protocols.
