Voice Call Agent Architecture

This diagram illustrates the multi-agent architecture for the voice call pipeline:

Key Components:

  • ToolCallingAgent: The central orchestrator that processes user requests and manages voice call operations
  • ToolCollection: Manages the available tools and capabilities that the agent can use
  • voice_mcp_server.py: Provides an MCP-compatible interface for voice call operations
  • voicecall.py: Core implementation that handles call setup, management, and termination

External Services:

  • External Voice Service: Third-party service (defined by VOICE_SERVER_URL) that handles the actual audio communication

Storage: Call data is stored in dedicated directories:

  • recordings/: Stores audio recordings from calls
  • transcriptions/: Contains text transcriptions of voice conversations
  • call_data/: Maintains metadata about calls and their status

Architecture Patterns Used:

  • Sequential: Process flow from query understanding to call execution to result processing
  • Human-in-the-loop: Integrates human participants (callers) in the agent workflow
  • Router: Directs conversation flow based on caller responses and context

This system enables an AI agent to initiate, manage, and participate in voice calls with humans, handling the complexities of real-time audio communication while maintaining context and purpose throughout the conversation.
